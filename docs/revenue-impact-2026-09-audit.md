## 3. 이 분석이 새로 찾은 (−) 항목

수익을 **깎을 수 있는데** 감사 보고서가 세지 않은 것들.

### 3-1. 즉시 고침 — `/qna` 빈 화면 광고 (이 커밋에서 수정)
죽은 칩을 고치면서 가드까지 제거해, "검색 결과가 없습니다" 빈 화면 **위에**
InArticleAd + 쿠팡 배너가 남았다. 콘텐츠 없는 지면의 광고는 AdSense 정책 접점이다.
칩 id 를 이미 고쳤으므로 가드는 이제 진짜 무매칭에서만 발동한다 → **가드 복원**.

### 3-2. 홈 meta description 이 진행 중 CTR 실험 문자열이었다 [최상]
`src/app/layout.tsx:49` 주석이 스스로 *"SERP CTR 강화(7차): 숫자 hook + 차별점 명시.
데스크톱 CTR 1.3%→3%+ 목표"* 라고 적은 실험 대상 문자열을, a99c53b 가
"연봉 5000만 → 월 353만 / 1억 → 650만" → "**352만 / 648만**" 으로 바꿨다
(description·og·twitter 3곳). 이 문자열은 **홈 + `%s | 머니샐러리` 템플릿을 쓰는 전 페이지**의
기본 description 이고, 홈은 3개월 GSC 클릭의 **54.0%(361/668)** 다.
→ **9/13·9/20·9/21 판정에 절단점 표시가 필요하다.** 금액 변경(=정정)은 옳지만
판정창 오염은 별개 비용이다. `revenue-10x-plan:274` 가 L18 을 기각한 사유
("28일 재판정 창을 OPI 피크 직전 소비")와 같은 종류의 비용이 이미 발생했다.

### 3-3. 쿠팡 고지문이 `HomeTopAd` 를 밀어내렸다 — 41개 지면 [상]
`PageFooterAds.tsx:24-30` 순서는 `InArticleAd → CoupangBanner → HomeTopAd` 다.
고지문(11px × 2줄 + marginTop 8 ≈ **25~40px**)이 쿠팡 배너 아래 신설되면서
그 아래 `HomeTopAd` 가 그만큼 내려간다. 소비처는 **41개 파일**
(guides·salary-db·company·glossary·en·table layout 등).
`masterplan:189`("신규 UI는 항상 광고 아래")의 문자는 지켰으나
"광고 위 높이 증가 금지"의 취지는 `HomeTopAd` 기준으로 어겼다. 고지문 자체는
법적 필수이므로 되돌릴 수 없고, **순서를 `HomeTopAd → InArticleAd → CoupangBanner` 로
바꾸는 것이 유일한 무손실 해법**이지만 배치 변경이라 승인 큐 항목이다.

### 3-4. 표시 금액의 전면 하향 [중]
5,000만 353→**352**만, 1억 650→**648**만, 회사 직급별 표 430쪽 최대 **−21.1%**.
이 숫자들은 SERP 스니펫·OG 카드·홈 FAQ·`/table` 타일에 그대로 실린다.
정정은 반드시 옳지만 **CTR 부호는 (−)일 수 있고** 아무도 계상하지 않았다.

### 3-5. 자동광고(수익의 81~86%)에 닿는 레버가 0개 [구조적]
9개 레버 전부가 수동 유닛($2.63/일) 산술로만 값을 매겼다. 자동광고 배치 판정에
닿을 수 있는 두 항목이 미계상·미계측이다.
- `globals.css:664` `content-visibility: auto` + `contain-intrinsic-size: 0 400px` 가
  `.section-lg`·`.section-md` **전체**에 걸리고, 홈의 `Display2Ad` 가 실제로
  `.section-lg` 안에 있다(`HomeClient.tsx:236→250`). `AdPlacement` 는

  추정 높이가 걸리면 관찰자 발화 시점이 어긋난다.
  **`ad-audit.mjs`·`ad-depth-audit.mjs` 어느 쪽도 이 CSS 를 인지하지 않는다(grep 0건)** —
  즉 §4-2 실측표(11,212px 등)와 그 위에 세운 L9 base 자체가 아직 검증되지 않았다.

## 5. 그럼 이 감사는 무엇이었나

1. **수정 비용이 사실상 0**이다.
2. **손실 분포의 꼬리가 채널 상실(회복 불가)** 이다 — 쿠팡 계정·AdSense 계정.

**네이버 67.7% 브랜드 검색으로 되돌아오는 사이트가 계산을 틀리지 않는다는 신뢰**다.

## 6. 반증·확인 계획 (요약)

> **D0 = 병합·배포일.** `docs/metrics-log.md` 에 절단점을 먼저 기록하지 않으면 아래 전부 무효다.
> AdSense **'광고 단위' CSV 는 날짜 열 없는 계정 누적표**라 창 판정에 쓸 수 없다 —
> **날짜 지정 units CSV** 또는 **'날짜 및 광고 단위' 교차 보고서**를 지정한다.

| 시점 | 무엇을 | 갈리는 것 |
|---|---|---|
| 즉시 | `curl -sI -A "Googlebot-Image/1.0" .../api/og?...` → `X-Robots-Tag` 확인 | L4 구글축 = 0 확정 |
| 즉시 | 쿠팡 파트너스 공지·메일 8/31~ 정책 경고 건수 | 1건이라도 있으면 L8 base 6배 상향 |
| 즉시 | `ad-depth-audit.mjs` 의 googlesyndication abort 해제(`:116-118`) 후 재측정 | 11,212px 공백이 자동광고로 메워져 있으면 **L9 base $0.01 이하·low 음수 확정** |
| 즉시 | `.section-lg`/`.section-md` 인지를 두 감사 스크립트에 추가 | §4-2 실측표 자체의 유효성 |
| 9/13 | **GA4 집계축 `page_title` → `page_path` 전환**(미실행) 후 페이지별 조회 | **6개 레버의 1차 반증이 이 한 항목에 걸려 있다** |
| D+14 | AdSense '날짜 및 광고 단위' 교차(D−14 vs D+14), 유닛 9958502911 | Active View 가 53.5% 대비 +2%p 이상이면 L1 high 쪽 |
| D+28 | GSC 페이지 색인 보고서에 `/api/og` URL 신규 출현 | 1건이라도 나오면 L4 = 음수, Allow 원복 검토 |
| D+28 | GSC 성과(28일, KR), `/table/{weekly,hourly}` | 클릭 7건 이상이면 L3 색인축 지지 |
| 10/5 | **네이버 서치어드바이저 '검색 유입'**(수행 0회) 랜딩 분해 | 저장소 최대 계측 공백 — L3·L6·L7 전부 |
| 11/2 | AdSense **페이지 보고서** 최초 수령, `/calc/samsung-bonus` 페이지 RPM | $2.5 이하 + PV 점유 15%+ 면 L9 base $0.20~0.30 |

**결정적 산술**: 9개 레버 base 합 **일 $0.054**(검증자 원값 기준)는 사이트 일 수익의 **0.28%** 인데,
기준선 창 간 변동은 **$1~9 단위**다. 즉 이 감사분 전체가 AdSense 일별 보고서의
관측 해상도보다 **두 자릿수 아래**이고, 검출 가능한 유일한 도구(페이지 보고서)는
11/2 에 처음 오며 슬롯 분해가 없고, 그 도구가 전제하는 GA4 축 전환·맞춤 측정기준·
AdSense 링크는 모두 미실행이다.
