# 지표 로그 — 콘솔 내보내기 집계 1행/회 (2026-09-05 개설 · 2026-09-06 스키마 v2)

`scripts/metrics-ingest.mjs log` 가 append 하는 표. 세션표(`docs/operator-console-pack.md`)의 CSV 수령 직후 한 행씩 남긴다.
원본 CSV 는 리포 밖(`C:\Users\ruby1\.moneysalary-secrets\`)에 보관하고, 여기에는 **집계만** 쓴다 — 검색어·페이지·URL 목록 금지(계획 §8-8).

열 정의
- **날짜**: 기록일(YYYY-MM-DD). 같은 날 창이 다르면 행을 나눈다.
- **창**: 각 지표의 집계 기간(예: `9/13 기준 28일`, `8/31~9/4`). 지표마다 창이 다르면 모두 적는다.
- **GA4 세션·소스 점유**: `ga4-sources` 결과 — 세션 합계와 그룹 점유(네이버=naver organic+m.search.naver.com referral 합산 / direct / 사내망=samsung.net·menlosecurity·teams·office / google / bing·yahoo·ddg / AI=chatgpt·copilot·claude·perplexity·gemini / 커뮤니티=dcinside·fmkorea·everytime·instagram·facebook·threads·blog·cafe 등 / other).
- **GSC 커버리지**: `gsc-coverage` 결과 — 색인/미색인 수·색인률, 사유 상위 3, `/salary-db/listed/` 섹션 색인률(10/19 lite 게이트 입력).
- **GSC 28일 블록**(v2 신설): 최근 28일 블록의 **4지표 = 클릭·노출·CTR·노출가중순위** + 블록추이(오래된 블록부터 클릭 수). 클릭 총량만 적으면 '뉴스 계단'과 '구조적 성장'이 갈리지 않는다 — 2026-09-06 실측에서 블록 클릭은 147→190→237→535(×1.29→×1.25→×2.26)인데 노출가중순위는 17.23→6.60→9.02→7.20, CTR 은 19.32→19.51→12.23→14.24% 로 오히려 하락했다. 즉 마지막 블록의 ×2.26 은 순위·CTR 개선이 아니라 노출량(27.2→134.2/일) 증가이고, 그리고 **8/15~9/3(20일) 순증 클릭 449 중 58.8%(264)가 `/calc/samsung-bonus` 단일 페이지**의 뉴스 사이클이다(이 58.8%는 20일 창 기준이며 마지막 28일 블록 순증 298 대비 비율이 아니다 — 창을 바꿔 인용하지 말 것). **블록비만 보고 성장률을 외삽하지 말 것.**
- **AdSense**: `scripts/adsense-report.mjs window/units` 요약을 텍스트로(일 수입·PV·페이지 RPM·노출/PV·Active View·수동 유닛 커버리지). 여기서 재계산하지 않는다.
- **ex-mux 커버리지**(v2 신설): 수동 유닛 커버리지를 **총 / 멀티플렉스 제외** 두 값으로 병기. 멀티플렉스(1910866475)는 커버리지 39.51%·미매칭 3,688건(계정 전체 미매칭 20,980의 17.58%)으로 총 커버리지를 혼자 끌어내린다(2026-09-06 누적 총 93.34% vs ex-mux 94.40%). **멀티플렉스가 배치돼 있는 이상 총 커버리지는 사이트 건강 게이트로 쓸 수 없다** — 게이트 판정은 ex-mux 값으로 한다.
- **비고**: 판정·경고·재측정 예정일. 기각 레버·추정치 금지.

★AdSense '광고 단위' CSV 주의 — 그 보고서에는 **날짜 열이 없다(계정 누적표)**. 특정 창의 값으로 읽으면 안 되고, 실험 전/후·회수·특정일 커버리지 분해 같은 창 판정에 쓸 수 없다. 기간 확정 절차(일별 누적 합계 대조 + 두 내보내기 간 델타로 시간당 노출률 역산)는 `scripts/metrics-ingest.mjs` 머리말 주석에 확정 기록해 두었으므로 재조사하지 말 것. 창 판정이 필요하면 **날짜 지정 units CSV** 또는 '날짜 및 광고 단위' 교차 보고서를 요청한다.

명령 예(원본 경로는 절대 경로):
```
node scripts/metrics-ingest.mjs gsc-coverage <표.csv> <차트.csv> --not-indexed <발견됨.csv> --not-indexed <크롤링됨.csv> --out <gsc.json>
node scripts/metrics-ingest.mjs ga4-sources <소스매체.csv> --out <ga4.json>
node scripts/metrics-ingest.mjs log --date 2026-09-13 --window "9/13 기준 28일" --ga4 <ga4.json> --gsc <gsc.json> --adsense "…" --note "…"
node scripts/metrics-ingest.mjs log --date 2026-09-13 --window "8/16~9/12" \
  --gsc-block-window "8/16~9/12" --gsc-block-clicks 535 --gsc-block-impr 3757 --gsc-block-ctr 14.24 --gsc-block-pos 7.20 \
  --gsc-block-prev "147,190,237" --coverage-total 93.34 --coverage-exmux 94.40 --note "…"
```
`--gsc-block "<자유 텍스트>"` 는 구조화 플래그 대신 쓰는 예외 경로이며 둘을 함께 주면 거부된다. CTR 은 생략하면 클릭/노출로 자동 계산되고, 직접 준 값이 0.5pt 넘게 어긋나면 오류로 멈춘다.
