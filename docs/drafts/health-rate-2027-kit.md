## 2. 운영자에게 받을 입력 3개 (배포 전 재검산 필수)

| # | 입력 | 형식 | 검산 |
|---|---|---|---|
| ① | 2027 **총** 보험료율 | `{RATE_TOTAL}` % (예: 2026년은 7.19) | 보도자료의 "보험료율 X.XX%"가 **총요율**인지 확인 |
| ② | 2027 **근로자** 부담률 | `{RATE_EMP}` % (예: 2026년은 3.595) | **`{RATE_EMP} = {RATE_TOTAL} ÷ 2`** 로 반드시 재계산. 7.19 → 3.595 처럼 소수 셋째 자리까지 |
| ③ | 시행일·부과체계 | 시행일 `2027-01-01` 가정 / 정률 구조(보수월액 × 요율) 유지 여부 | 시행일이 1/1이 아니거나 정률 구조가 바뀌면 **중단 후 운영자 재확인** (셸 체크리스트 3과 동일) |

부수 값
- `{DATE_DECIDED}` = 건정심 의결일 (예: 2026-09-08), `{DATE_DEPLOY}` = 배포일.
- `{RATE_EMP_DEC}` = `{RATE_EMP} ÷ 100` 을 코드 리터럴로 (3.595 → `0.03595`). `{RATE_EMP_DIGITS}` = 그 소수부 (`03595`).
- 인상 시 파생값(§4-A 문안용): `{DELTA_PP}` = `{RATE_TOTAL} − 7.19` (총요율 인상폭, %p) / `{LTC_EMP}` = `{RATE_EMP} × 0.1314` (소득 대비 장기요양 근로자분, 소수 셋째 자리; 2026은 0.472) / `{TOTAL_EMP_PCT}` = `5.0 + {RATE_EMP} + {LTC_EMP} + 0.9` (둘째 자리; 2026 준용 시 9.97) / `{TOTAL_DIFF_PP}` = `{TOTAL_EMP_PCT} − 9.72` (2026 실제 합계 4.75+3.595+0.472+0.9 = 9.717).

**오입력 방지 3가지 (모두 2025-08-28 2026 요율 결정 보도에서 실제로 혼재한 숫자 유형)**
1. 헤드라인 "보험료율 7.19%"는 **총요율**이다. 이 값을 근로자 카드(`selfRate`)나 `NET_SALARY_RATES_2027.health`에 넣으면 공제가 2배가 된다. `health`에는 **근로자율 ÷ 100**만 들어간다.
2. 보도의 "1.48% 인상"은 **인상률(상대비)**, "+0.1%p"가 **요율 차이**다. 문안의 `{DELTA_PP}` 자리에 인상률을 넣지 말 것.
3. "지역가입자 점수당 금액(원)"은 이 사이트 대상이 아니다. 직장가입자 정률만 반영.
