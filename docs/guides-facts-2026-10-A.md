# 가이드 재작성 사실 원장 — A (W2-C 준비 · 2026-09-26)

- 대상: 1차 키퍼 12편(연말정산), 2차 키퍼 13편(성과급 세금·4대보험·회사 성과급)과 GUIDES-08 잔여 문장 정정에 쓰는 숫자. 키퍼·통합 지도는 `docs/guides-keepers-2026-10.md`.
- 형식: 주장 → 공식 출처 URL → 값 → 기준일(시행일·고시일·페이지 기준일) → 확인 결과. 보도·블로그는 단서로만 썼고, 공식 1차 자료가 없는 값은 F 절에 따로 모아 "보도 기준"으로 표시했다.
- 확인 방법: 2026-09-26 에 모든 URL 을 브라우저 UA(Chrome 128) curl 로 GET 해 HTTP 200 을 확인했다(아래 44건 전부 200). law.go.kr 가독 URL(`/법령/<법령명>/<조문>`)은 셸만 200 이고 조문은 iframe(`/LSW/lsSideInfoP.do?lsiSeq=…&joNo=<4자리>&joBrNo=<2자리>…`)에 실리므로, 그 iframe 본문에서 조문 문구와 시행일을 읽었다. 표·산식 조문(§47·§22③·§59①)은 iframe 의 `@@LATEX@@` 대체 텍스트로 확인했다.
- 숫자는 사이트 정본 상수(`src/lib/cardDeduction2026.ts`, `src/lib/taxConstants2026.ts`, `src/config/unemploymentBenefit.ts`, `src/app/calc/samsung-bonus/opiData.ts`·`taiData.ts`, `src/app/calc/sk-hynix-bonus/psData.ts`)와 글자 그대로 같아야 한다. 가이드 본문은 TS 템플릿 문자열이므로, 키퍼 표 안에서 verify:tax 가 감시하는 2026 요율·상한은 guideSpec (5) 규칙대로 상수를 import 해 `${…}` 로 끼운다(hot-news-2026-deep-dive.ts 의 UNEMPLOYMENT_BENEFIT_2026 패턴). 보간하지 않는 문장·description·metaDescription 은 여기 값을 그대로 옮기고 출처를 적는다.
- 확인 결과 표기: `200·시행 YYYY.M.D` = 조문 시행일, `200·고시/기준 …` = 고시·페이지 기준일, `200·보도` = 공식 1차 자료 아님.
