# 카카오톡 "진짜 공유" 켜는 방법 (5~10분, 무료)

지금 사이트의 카카오 버튼은 키가 없어서 "링크 복사"로만 동작합니다.
아래 4단계만 하면 진짜 카톡 공유창(노란 카드 미리보기)이 열립니다.
**키를 등록하기 전까지 사이트는 지금과 완전히 동일하게 동작하니 서두르지 않아도 됩니다.**

## 1단계 — 카카오 개발자 앱 만들기
1. https://developers.kakao.com 접속 → 오른쪽 위 **로그인** (평소 쓰는 카카오 계정)
2. 상단 메뉴 **내 애플리케이션** → **애플리케이션 추가하기**
3. 앱 이름: `머니샐러리`, 회사명: `머니샐러리` (아무거나 무방) → 저장

## 2단계 — JavaScript 키 복사
1. 방금 만든 앱 클릭 → 왼쪽 메뉴 **앱 키**
2. **JavaScript 키** 옆의 값을 복사 (32자리 영숫자)
   - ⚠️ "REST API 키"나 "Admin 키"가 아니라 **JavaScript 키**입니다

## 3단계 — 사이트 도메인 등록
1. 왼쪽 메뉴 **플랫폼** → **Web 플랫폼 등록**
2. 사이트 도메인에 아래 한 줄 입력 후 저장:
   ```
   https://www.moneysalary.com
   ```

## 4단계 — Cloudflare Pages에 키 등록
1. Cloudflare 대시보드 → **Workers & Pages** → 사이트 프로젝트 선택
2. **Settings → Environment variables** → **Add variable**
   - 변수 이름: `NEXT_PUBLIC_KAKAO_JS_KEY`
   - 값: 2단계에서 복사한 JavaScript 키
   - **Production 과 Preview 양쪽 모두** 등록 (광고 슬롯 ID들과 같은 방식)
3. **Deployments 탭 → 최신 배포의 ⋯ 메뉴 → Retry deployment** (재배포해야 키가 반영됩니다)

## 확인 방법
재배포 완료 후 아무 계산기 페이지에서 노란 카카오 버튼을 누르면:
- **성공**: 카카오톡 공유창이 뜨고, 페이지 제목+썸네일 카드가 보임
- **실패(키 미반영)**: 지금처럼 "링크 복사 완료" 토스트가 뜸 → 재배포 여부와 변수 이름 오타 확인
